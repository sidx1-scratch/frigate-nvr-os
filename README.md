# Reporting Bugs 🐛

If you find any bugs while running the OS, please report them by opening a GitHub Issue. 

### For Contributors & Developers:
If you plan to submit a fix, please keep the following in the mind:
* **Build System:** Frigate NVR OS is built using **Buildroot**.
* **Configuration:** You can find the system configuration files in the `/config` directory of this repository.
